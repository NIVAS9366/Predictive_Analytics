# 📈 Predictive Analytics Using Historical Data

An end-to-end machine learning project that builds, trains, and evaluates a predictive model to forecast future retail sales and trends based on historical time-series data.

---

## 📌 Project Overview

Predictive analytics is a vital branch of advanced analytics that leverages historical data, statistical modeling, and machine learning to forecast future events and guide strategic business decisions. This project processes historical monthly sales data, handles feature engineering, trains a regression-based predictive model, evaluates performance metrics, and generates out-of-sample future forecasts.

---

## 🎯 Key Features & Workflow

* **Data Cleaning & Preprocessing:** Validates and handles historical datasets, checking for missing values and ensuring chronological alignment.


* **Exploratory Data Analysis (EDA):** Visualizes historical trends (`historical_sales_trend.png`) to identify growth patterns and underlying seasonality.


* **Machine Learning Modeling:** Implements a Scikit-Learn **Linear Regression** model to capture temporal trends.


* **Model Evaluation:** Assesses prediction accuracy using industry-standard metrics:


* **Root Mean Squared Error (RMSE)**
* **Mean Absolute Error (MAE)**
* **R-Squared ($R^2$) Score**


* **Visualization & Forecasting:** Plots test predictions against actual history (`predictive_analytics_results.png`) and generates out-of-sample forecasts for the next 12 months.
